# Call targets nothing actually calls: every `E8` byte pointing at one of these sits in data.
#
# Format: one guest address per line, hex, `#` starts a comment. tools/queue.js reads this and reports these rows
# as `excluded` rather than as work.
#
# WHY. The `E8 rel32` rule scans every byte of the image, so a byte pair inside a table can point anywhere, and the
# address it points at then decodes as plausible code and looks like a routine. The test that separates a real call
# target from one of these is whether the site of the call is an instruction start in EITHER walk. Both decoders are
# needed: with our walk alone the rule excludes 105 targets, because a call site inside a region our seeds never
# cover is not one of our instruction starts even when it is plainly code.
#
# WHERE FROM. Item 4o. The 30 starts fmtownskit never decodes were split by that test: 22 have no call site that is
# an instruction start in either walk, and 8 have one in ours but not theirs. Only the 22 are here. The 8 stay in the
# queue because the walks genuinely disagree about whether the caller is code, and a disagreement is not evidence.
#
# Re-derive with `node tools/calltargets.js`, which needs the recompiled module present. `--write` rewrites this file.
# `node tools/checkall.js` re-derives and compares when the module is available, and skips with a printed note when it
# is not, so a clone with only the disc is not told the check failed.
