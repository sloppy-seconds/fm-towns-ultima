About

Nothing is uploaded. The disk is read, edited and written entirely in this page, then you download the result. Your original file is never modified.

Open your save disk

Drop the .hdm or .img floppy image here, or use Open save disk. The one that ships with the game is called [UserDisk].hdm.

Drop a save disk here

No disk to hand? New blank disk builds a valid FM Towns save disk from scratch. It needs no boot sector: Ultima II only ever opens the floppy as a data volume, and was confirmed to accept a disk containing nothing but geometry and an empty filesystem.

Create a character

Stats are final values. Race, sex and profession bonuses were applied by the game when the character was created and are not re-applied here. FOOD is stored at a hundred times the displayed figure, so 40000 shows as 400, and it counts down as you travel.

Identity

Names are limited to 15 characters of letters, digits and spaces. The file format itself allows more, and any character could be written, but how the game renders a long or unusual name is unknown, so this page stays inside what is certain to work.

Attributes - 30 of 90 points left to spend

The game gives 90 points, with at least 10 in each attribute. Bonuses from the identity above are added after you spend them, and are shown next to each attribute as they apply.

Resources

Enter food as the number of rations you want. It is stored internally at one hundred times this figure, because the game counts down in fractions of a ration each turn. This page does that conversion.
